# MedInstruct ☤

**AI-Powered Medical Device Guidance**

MedInstruct is an AI assistant that delivers clear, instant instructions for over 13,400 medical devices, making it easy for nursing students, healthcare professionals, and educators to use devices safely and effectively.

---

## ✨ Features

- **Instant Lookup**: Enter device name, usage, or GMDN code for precise instructions.
- **Speech Recognition**: Hands-free query input via voice.
- **Smart Search**: Uses Transformers and FAISS for fast, context-aware results.
- **Clear Instructions**: Human-like guidance powered by Large Language Models.
- **Fast Backend**: Built with FastAPI for quick, reliable responses.

---

## 💡 Why It Matters

MedInstruct simplifies complex medical device manuals, providing actionable guidance when and where you need it, enhancing safety and efficiency in healthcare settings.
